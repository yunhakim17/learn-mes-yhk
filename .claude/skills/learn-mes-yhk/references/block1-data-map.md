## EXPLAIN

### 1. 정의

| 용어 | 뜻 |
|---|---|
| **MES** (제조 실행 시스템) | 작업 지시부터 실적·품질·설비 상태까지, 현장에서 "지금 무엇이 만들어지고 있는지"를 기록·관리하는 시스템 |
| **ERP** | 수주·구매·재고·회계처럼 회사 전체의 돈과 물건을 관리하는 시스템. MES의 바로 위 층 |
| **PLC** | 설비를 직접 움직이고 센서 값을 읽는 산업용 제어기. MES의 아래 층 |
| **ISA-95** | 공장 시스템을 층으로 나눠 각 층의 일과 데이터 주고받기를 정한 국제 표준 — "MES가 어디 있나" |
| **MESA-11** | MES의 일을 기능 단위로 나눈 모델 — "MES가 무엇을 하나" |

ISA-95는 공장을 Level 0~4의 다섯 층으로 나누고, MES는 Level 3에 있다 [S1][S2].

| 층 | 하는 일 | 대표 시스템 | 부품 공장 데이터 예 |
|---|---|---|---|
| Level 4 | 경영·물류 | ERP | 수주량, 납기일, 자재 재고 |
| **Level 3** | **최종 제품을 만드는 작업 흐름** | **MES** | 작업 지시, 생산 실적, LOT 번호, 검사 결과 |
| Level 2 | 공정 모니터링·제어 | PLC, DCS, SCADA | 설비 가동/비가동, 알람 |
| Level 1 | 감지와 조작 | 센서, 지능형 디바이스 | 온도, 압력, 진동, 토크 |
| Level 0 | 실제 물리 공정 | 프레스, 용접기, 사출기 | (물리적 움직임 자체) |

MESA-11은 MES의 핵심 기능을 11개로 정의한다 [S2][S11]: 상세 일정 계획 · 자원 할당·상태 · 작업 지시 · 데이터 수집 · 노무 관리 · 문서 관리 · 품질 관리 · 제품 추적·이력(LOT) · 공정 관리 · 설비 보전 관리 · 성과 분석.

### 2. 왜 지도부터 그리나

| 기준 | 시스템 이름만 아는 경우 | 층 지도로 보는 경우 |
|---|---|---|
| 알람이 늦게 보일 때 | "시스템이 느리다"로 끝난다 | 어느 층과 층 사이가 끊겼는지 찾는다 |
| MES의 위치 | 여러 시스템 중 하나 | 아래(설비·품질)와 위(주문·납기)를 둘 다 가까이에서 보는 자리 |

품질·납기 문제를 사람보다 먼저 보려면 그 신호가 어느 층에서 생기고 어느 층까지 올라가야 보이는지 알아야 한다. 센서는 이미 이상을 알고 있는데 ERP 화면에는 내일 아침에야 뜨는 일은 대부분 층 사이 연결이 끊겨 있어서 생긴다.

### 3. 케이스 — 자동차 모터 라인 (삼성SDS 사례, 2020년경 자료) [S10]

- **Level 1~2 → 3:** 모터 생산라인의 설비 정보를 실시간으로 모으고 설비 인터페이스를 표준화해, 라인 추가·설비 변경에 대응할 확장성을 확보했다고 설명한다.
- **Level 3 안에서:** 수입·공정·출하 검사를 잇고, 바코드로 자재 투입을 기록해 LOT을 추적했다.
- **Level 3 ↔ 4:** ERP와 생산계획·자재 입고·출하 실적을 주고받아 자재 부족과 납기 지연을 줄였다고 설명한다.
- 불량률·리드타임이 얼마나 줄었는지 정량 수치는 공개되지 않았다(미확보).

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
mes-lab 폴더에서 1장 실습을 해 줘.
1. facts.csv 에서 F01(ISA-95 계층 수), F02(MES 위치), F03(MESA-11 기능 수) 행을 읽어 줘.
2. ISA-95 Level 4부터 Level 0까지 다섯 층을 표로 정리해 out/ch1_map.md 로 저장해 줘.
   칸: 층 · 하는 일 · 대표 시스템 · 부품 공장 데이터 예. MES 행은 굵게.
   표 아래에 facts.csv 에서 읽은 숫자와 출처 번호를 [S1]처럼 적어 줘.
3. out/ch1_map.json 에 {"layers": 층 수, "mes_level": MES 층 번호, "mesa_functions": 기능 수} 를
   facts.csv 값 그대로 숫자로 저장해 줘.
4. facts.csv 에 없는 숫자는 만들지 마. facts.csv 는 고치지 마.
5. 끝나면 ch1_map.md 표를 화면에 보여 줘.
```

### 확인할 것 (Phase B)

- `out/ch1_map.json`이 `layers` = 5, `mes_level` = 3, `mesa_functions` = 11이다.
- `out/ch1_map.md`에 다섯 층 표가 있고 MES 행이 Level 3이며, 출처 [S1]·[S2]가 적혀 있다.

막히면 "ch1_map.json 의 값을 facts.csv F01~F03 과 한 줄씩 대조하고, 다르면 어디서 틀렸는지 찾아 줘"라는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.
