# 실습 데이터

| 파일 | 내용 | 행 수 | 실데이터/가상 | 출처 |
|---|---|---|---|---|
| `facts.csv` | 교재에 쓴 숫자 (id · 장 · 주장 · 값 · 단위 · 기준연도 · 출처 · 교차확인 · 비고) | 24 | 실데이터 — 공개 보도·표준 단체·시장조사 보도자료에서 뽑음 | 출처 번호 S1~S16 → `sources.md` |
| `sources.md` | 출처 목록 (번호 · 제목 · 기관 · 발행일 · 주소 · 신뢰도) | 16건 + 참고 2건 | — | 각 행의 원문 URL |

- 가상 데이터는 없다. 부품사 실제 MES 로그(F23)와 도입 후 불량률·리드타임 수치(F15)는 공개 자료를 찾지 못해 '미확보'로 남겼다.
- 회사 내부 숫자는 이 폴더에 넣지 않는다.
