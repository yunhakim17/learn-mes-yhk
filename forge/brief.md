## 원본에서 뽑은 것

| 구분 | 내용 |
|---|---|
| 오늘의 메시지 | 1 MES는 ISA-95 다섯 층 중 Level 3, 납기와 품질 신호가 만나는 자리 · 2 OEE(가용률×성능×품질)로 설비·품질·납기 데이터를 묶는다 · 3 후행 지표 대신 선행 신호를 본다 |
| 실습 단계 | 교재에 실습 단계는 없다 → 장마다 '케이스'와 표를 facts.csv 숫자로 다시 만들어 보는 실습으로 옮긴다 |
| 실습과제 · 모범답안 | 교재 '생각해 볼 질문' 장마다 3개 (모범답안 없음 → 퀴즈 재료로만 사용) |
| 정답 수치 | F01 5층 · F02 Level 3 · F03 11개 · F09 90/95/99.9 → OEE 85.4% (품질 99%면 84.6%) · F18 경남 품질 +44.3%가 네 지표 중 최대 · F20 전국 품질 +42.5%가 세 지표 중 최대 |

## 가정과 확인 필요
- 교재에 '실습'이 없으므로, 실습은 facts.csv 숫자로 교재 표·계산을 다시 만들어 확인하는 형태로 한다(새 내용 추가 없음).
- 부품사 실제 MES 로그는 〔미확보〕(F23) → 가상 데이터도 만들지 않는다.
